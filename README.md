# GandhiVerse 🇮🇳

## 📖 About the Project

GandhiVerse is an interactive React-based web application dedicated to the life, philosophy, freedom movements, and legacy of Mahatma Gandhi.

The platform provides an engaging and educational experience through:

- 📜 Historical Timeline
- ✊ Freedom Movements
- 🖼️ Image Gallery
- 🎬 Video Library
- 📚 Books Collection
- 🌍 Global Legacy
- 🏛️ Gandhi Museums
- 🧠 Interactive Quiz
- 👨‍💻 Developer Profile

The project aims to make Gandhi's journey accessible to students, educators, and history enthusiasts through a modern digital experience.

---

## 🚀 Features

### 🏠 Home Section
Beautiful hero banner introducing Mahatma Gandhi.

### 📜 Timeline
Explore major milestones in Gandhi's life from 1869 to India's independence.

### ✊ Freedom Movements
Learn about:

- Champaran Satyagraha
- Non-Cooperation Movement
- Dandi March
- Quit India Movement

### 🖼️ Gallery
Historical photographs and memorable moments from Gandhi's life.

### 🎬 Video Library
Watch documentaries and historical videos related to Gandhi and India's freedom struggle.

### 📚 Books
Access Gandhi's famous books and writings.

### 🌍 Legacy
Discover how Gandhi influenced world leaders including:

- Martin Luther King Jr.
- Nelson Mandela
- Dalai Lama

### 🏛️ Museums
Explore important Gandhi museums and memorials.

### 🧠 Quiz
Test your knowledge about Gandhi's life and contributions.

### 👨‍💻 Developer Section
Developer profile with social media links and contact information.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/prashant-yadav/GandhiVerse.git
```

Move into the project directory:

```bash
cd GandhiVerse
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
